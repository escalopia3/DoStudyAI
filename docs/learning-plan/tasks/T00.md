## 实施检查点

1. 检查 JDK/Node/Maven wrapper、中间件连接方式和工作区 Git 状态；只记录配置名称，不打印密钥。
2. 运行 OLD-BE、OLD-FE、BUILD-FE、OLD-EXT；区分原有失败与缺环境，保存退出码和测试数量。
3. 列出旧接口与页面基线，含四模式/AUTO、转写、MP3、追问、修订、SSE、失败重投、扩展、Demo；无法执行项列为 NOT_RUN。

每完成一个检查点就保存已验证事实；上下文不足时更新交接后继续当前包，不跳到后续任务。
