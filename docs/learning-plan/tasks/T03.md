## 目标

新增 learning 模块壳、条件加载、鉴权接入和独立执行配置。

## 修改范围

新 Java learning/config、learning/security 及其 tests；允许最小改 WebConfig 和追加命名空间配置。

共享文件仅做任务明确需要的最小改动。未列出的必要支持文件先列入本包计划并说明理由；涉及旧契约、范围或其他包的公共接口时按变更规则处理，不静默扩大任务。

## 实施检查点

1. 关闭开关时不加载新消费者、调度器和外部凭证依赖，旧应用可启动。
2. 新增有界执行器和新接口鉴权；新模型/解析配置独立，保留旧方法、CORS 来源和旧执行器。
3. 定义模块能力开关：未完成 handler/API 不进入用户可用路径。

每完成一个检查点就保存已验证事实；上下文不足时更新交接后继续当前包，不跳到后续任务。

## 必须交付

- LearningConfiguration、授权入口与配置测试。
- `handoffs/T03.md` 与该包实际证据路径。
- STATUS.json 中真实状态、验证结果和下一包；不复制其他包的报告作为本包结果。

## 验收

- [ ] learning.enabled=false 且缺新凭证时启动通过；旧 API/SSE 鉴权未改变。
- [ ] 新接口不能匿名访问；新增队列拒绝不写旧任务状态。
- [ ] 修改范围和原功能兼容检查通过。
- [ ] 必需验证已执行且可复现，未执行项明示。
- [ ] 交接中的公开接口名称、路径及迁移号与代码一致。

验证要求：U + Spring 上下文 + OLD-BE；建议 LearningModuleIsolationTest。

命令选择按 TESTING.md 执行；建议测试类名/目录是待创建产物，先核实再运行。记录工作目录、原样命令、退出码、用例数量、环境及代码摘要。集成/模型检查缺环境时保留 VERIFY_PENDING 或 BLOCKED，不改测试条件制造通过。

## 不做与停止边界

不添加所有未来业务服务；不修改旧 Bean 默认配置。

当前包完成后停止；默认不自动执行下一包。发现依赖和代码不符时记录差异，暂停依赖该事实的工作，不能编造“已有服务”。
