## 实施检查点

1. prepare-video 幂等懒关联；聚合旧视频和文档的稳定游标列表，不批量迁移视频。
2. 成员加入/移动/移出，membership_version 更新，跨 owner 防护，资料及单资料笔记保留。
3. 成员变更记录待索引状态和耐久事件；T25 前不把知识库标 READY、不伪造成功索引 job。

每完成一个检查点就保存已验证事实；上下文不足时更新交接后继续当前包，不跳到后续任务。
