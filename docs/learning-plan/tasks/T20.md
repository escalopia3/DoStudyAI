learning/note persistence、revision/import/export API；对应迁移/tests。

共享文件仅做任务明确需要的最小改动。未列出的必要支持文件先列入本包计划并说明理由；涉及旧契约、范围或其他包的公共接口时按变更规则处理，不静默扩大任务。

## 实施检查点

1. 新增笔记/版本/引用表和 scope 约束、expectedVersion、幂等编辑。
2. 实现版本读取、Markdown 导出、恢复旧版生成新版本；无课程 RESOURCE 合法。
3. 导入旧学习结果不调模型、不重跑分析；缺来源标 NEEDS_REVIEW。

每完成一个检查点就保存已验证事实；上下文不足时更新交接后继续当前包，不跳到后续任务。

## 必须交付

- 笔记版本 APIs、旧结果转换器。
- `handoffs/T20.md` 与该包实际证据路径。
- STATUS.json 中真实状态、验证结果和下一包；不复制其他包的报告作为本包结果。
