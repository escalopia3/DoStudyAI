## 实施检查点

1. 实现 GET job、events、cancel、retry；owner 从登录态取得。
2. MySQL sequence 真源，Redis 通知，订阅后补最新状态，客户端丢旧事件。
3. 断连可轮询，永久 401/403/404 不无限重连；不承诺历史事件全重放。

每完成一个检查点就保存已验证事实；上下文不足时更新交接后继续当前包，不跳到后续任务。
