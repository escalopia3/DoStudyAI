## 实施检查点

1. 完整 OLD-BE/FE/EXT/build、旧客户端手工链路、历史数据升级、开关关闭/开启验证。
2. 同机三次旧流量/混合流量比较；不达门槛先降新并发或拆学习 Worker。
3. 备份副本迁移、开关回退、含新增 migration 的兼容回退包演练；登记 G6。

每完成一个检查点就保存已验证事实；上下文不足时更新交接后继续当前包，不跳到后续任务。
