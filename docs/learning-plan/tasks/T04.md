## 实施检查点

1. 分配未使用迁移版本并建基础六表；旧 media 不新增阻止删除的外键。
2. 实现 owner 查询、唯一 media 映射、唯一资源归档、revision 序号与行版本。
3. 用已有数据副本验证迁移前后旧表/读写兼容；不创建后续笔记/复习表。

每完成一个检查点就保存已验证事实；上下文不足时更新交接后继续当前包，不跳到后续任务。
