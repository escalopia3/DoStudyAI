- 当前代码核对：POI HWPF/HSLF、独立 scratchpad 依赖；T02 旧格式样本。

## 修改范围

learning-parser 的 legacy adapters 与 tests。

共享文件仅做任务明确需要的最小改动。未列出的必要支持文件先列入本包计划并说明理由；涉及旧契约、范围或其他包的公共接口时按变更规则处理，不静默扩大任务。

## 实施检查点

1. 分别实现 DOC 段落和 PPT 页文本；按格式保留定位。
2. 文件头/MIME/扩展名联合校验，复杂布局降级、加密/损坏明确失败。
3. 旧格式异常不影响现代格式适配器。

每完成一个检查点就保存已验证事实；上下文不足时更新交接后继续当前包，不跳到后续任务。
