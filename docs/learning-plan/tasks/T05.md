## 修改范围

learning/job/model、job/repository；jobs/outbox 新迁移与 tests。

共享文件仅做任务明确需要的最小改动。未列出的必要支持文件先列入本包计划并说明理由；涉及旧契约、范围或其他包的公共接口时按变更规则处理，不静默扩大任务。

## 实施检查点

1. 实现 job 类型、状态、owner/resource/course 可空规则及幂等键。
2. 任务与 Outbox 原子写入，重放相同 key 返回原 job，输入不同时返回契约冲突。
3. 提供租约领取/续约/fencing 的原子 repository 操作及 sequence 更新。

每完成一个检查点就保存已验证事实；上下文不足时更新交接后继续当前包，不跳到后续任务。
