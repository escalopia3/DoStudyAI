## 实施检查点

1. 分块提炼与聚合，固定 source manifest，用户要求不改授权范围。
2. 笔记内容和引用 sectionId 结构化；服务器补全 locator；上下文不足明确标记。
3. 阶段检查点、调用前预算和取消；模型配置独立，不修改旧 DeepSeek 默认行为。

每完成一个检查点就保存已验证事实；上下文不足时更新交接后继续当前包，不跳到后续任务。
